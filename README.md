# La Grulla Blanca — versión web

Juego experimental R2–R18, distribución modular HTML/JavaScript/CSS.

- Repositorio de publicación: **solo distribución web**. El desarrollo y los respaldos permanecen en un repositorio privado separado.
- La publicación utiliza exclusivamente los archivos `dist/` compilados y verificados del proyecto.
- La versión inicial conserva el bloqueo de WORLD y no implica certificación global del Arco 1.
- Las partidas se guardan en el navegador (IndexedDB); no se transfieren automáticamente desde localhost ni desde otro dominio.
- Para jugar, accedé al sitio de GitHub Pages cuando figure como publicado en **Settings → Pages**.

Este repositorio se prepara para alojar los 331 recursos verificados de la distribución modular R2–R18.
